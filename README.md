# 🌙 Dream Cycle — Sleep Calculator

**Stop waking up groggy. Sleep smarter with the 90-minute cycle rule.**

Waking up in the middle of a sleep cycle leaves you drowsy and foggy. Waking up *at the end* of one leaves you refreshed — even with less total sleep. Dream Cycle does the math for you.

## ✨ Features

- 🛏️ **Bedtime → wake times:** enter when you'll fall asleep, get 4 ideal wake-up times (each the end of a full 90-minute cycle)
- ⏰ **Wake time → bedtimes:** enter when you must wake up, get the ideal bedtimes to hit
- 🌙 **"I go to bed NOW" button** — one tap, instant wake-up options
- ⭐ **Sweet-spot highlight** — the 7.5–8 hour option is marked so you can aim for it
- 📱 Fully responsive, dark sleepy UI — works great on phones

## 🚀 Run it in 30 seconds

No build step, no dependencies. Just:

1. Download or clone this repo
2. Open `index.html` in any browser
3. Pick a mode, set your time, done

Or run a quick local server:

```bash
npx serve .
```
